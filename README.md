## The Idea

iMuse is a personal cultural universe built around the things you love, discover and want to remember.

It brings together different forms of inspiration into one visual space, allowing you to collect meaningful experiences, explore unexpected connections and gradually build a reflection of your own taste.

Not another media tracker. Not another bookmarking tool.

**A space that feels like yours.**

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/harsheellhu/IMuse.git
cd IMuse
```

Install dependencies:

```bash
npm install
```

Create your environment file:

```bash
cp .env.example .env
```

For Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Configure the required environment variables in `.env`. Replace the default secrets with your own values. Google OAuth credentials are needed if you intend to use Google sign-in.

### Run the application

```bash
npm run dev
```

Frontend: `http://localhost:3000`

Backend: `http://localhost:3001`
